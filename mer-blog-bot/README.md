# 메르 블로그 새 글 → 텔레그램 요약 알림 봇

메르 블로그(`ranto28`)에 새 글이 올라오면 2분 안에 Claude가 요약해서 텔레그램으로 보내 줍니다.

```
메르 블로그 → 파이썬(2분마다 확인) → Claude Code(새 글 있을 때만 요약) → 텔레그램 봇 → 내 휴대폰
```

## 받는 메시지 예시
```
📌 [메르] 글 제목
🎯 결론: 핵심 결론 한 문장

• 핵심 1
• 핵심 2
• 핵심 3

💡 내 관점: 부동산/금융자산 시사점 한 줄
🔗 원문 링크
```

---

## 설치 (윈도우 PC, 처음 1회)

### 1. 파이썬 설치
- https://www.python.org/downloads/ 에서 3.11 이상을 설치합니다.
- 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.

### 2. 이 폴더 준비
명령 프롬프트(cmd)를 열고 `mer-blog-bot` 폴더로 이동합니다.
```
cd C:\경로\mer-blog-bot
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

### 3. Claude Code 확인
```
claude -p "안녕"
```
답이 나오면 정상입니다. 안 나오면 Claude Code를 설치하고 로그인하세요.

### 4. 텔레그램 봇 만들기 (교재 p.45)
1. 텔레그램에서 `@BotFather`를 검색합니다. (파란 체크 표시가 있는 공식 계정)
2. `/newbot` → 봇 이름(예: `메르 요약 Agent`) → 봇 아이디(끝이 `bot`, 예: `my_mer_summary_bot`)를 보냅니다.
3. BotFather가 준 **토큰**(`123456789:AA...`)을 복사합니다. 토큰은 비밀번호와 같으니 남에게 보여 주지 마세요.
4. 방금 만든 봇과의 대화방을 열고 `/start`를 보냅니다.
5. 브라우저에서 아래 주소를 엽니다. (`<토큰>` 자리에 토큰을 넣으세요)
   `https://api.telegram.org/bot<토큰>/getUpdates`
   나온 결과에서 `"chat":{"id":123456789` 의 숫자가 **chat_id**입니다.

### 5. 설정 파일 작성
`.env.example`을 복사해서 이름을 `.env`로 바꾸고, 토큰과 chat_id를 채웁니다.

### 6. 시험 실행
```
.venv\Scripts\python mer_bot.py --test --dry-run
```
최신 글 요약이 화면에 나오는지 확인합니다. (텔레그램으로는 보내지 않음)
```
.venv\Scripts\python mer_bot.py --test
```
텔레그램으로 메시지가 오는지 확인합니다.
```
.venv\Scripts\python mer_bot.py --init
```
지금까지 올라온 글을 모두 '읽음' 처리합니다. **반드시 한 번 실행하세요.** 안 하면 첫 실행 때 옛날 글이 쏟아집니다.

### 7. 2분마다 자동 실행 (작업 스케줄러)
1. 시작 메뉴에서 **작업 스케줄러**를 엽니다.
2. 오른쪽 **작업 만들기** → 이름은 `메르봇`
3. **트리거** 탭에서 **새로 만들기**를 누릅니다.
   - 시작: 지금 시각
   - 고급 설정에서 **작업 반복 간격: 5분**을 고른 뒤 칸에 직접 `2분`으로 고쳐 입력합니다.
   - 기간: **무기한**
4. **동작** 탭에서 **새로 만들기**를 누릅니다.
   - 프로그램: `run_bot.bat` 전체 경로
   - 시작 위치: `mer-blog-bot` 폴더 경로
5. **조건** 탭에서 "AC 전원일 때만 시작"을 해제합니다. (노트북인 경우)
6. **설정** 탭에서 "이미 실행 중이면: 새 인스턴스 시작 안 함"을 선택합니다.
7. Windows 설정 → 전원 → **절전 모드: 안 함**으로 바꿉니다.

## 확인과 문제 해결
- 실행 기록은 `logs\bot.log`에 남습니다.
- **`claude 명령을 찾을 수 없음`**: `.env`의 `CLAUDE_CMD`에 전체 경로를 적습니다. 경로는 cmd에서 `where claude`로 확인할 수 있습니다.
- **`요약 실패` 메시지가 옴**: Claude 사용 한도 초과나 로그인 만료일 수 있습니다. `claude -p "안녕"`을 다시 실행해 보세요.
- **텔레그램이 안 옴**: 토큰과 chat_id를 확인하고, 봇에 `/start`를 보냈는지 확인합니다.

## 주의
- 요약은 **개인 열람용**입니다. 블로그·SNS에 다시 올리면 저작권 문제가 생길 수 있습니다.
- PC가 꺼지거나 절전 상태가 되면 알림도 멈춥니다.
- 네이버가 페이지 구조를 바꾸면 본문을 읽지 못할 수 있습니다. 그때는 RSS 요약문으로 대신 요약합니다.
