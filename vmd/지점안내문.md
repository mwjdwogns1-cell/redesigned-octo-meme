# 📋 VMD 주간 제출 안내 (지점용)

> 단톡방에 그대로 복사해서 공유하세요.

---

**[VMD 주간 제출 방법 안내]**

이번 주부터 VMD 취합을 **링크 하나**로 받습니다.
카톡 사진 전송·엑셀 정리 없이 **30초**면 끝납니다.

**▶ 제출 링크**
`여기에 웹앱 주소 붙여넣기`

**▶ 제출 방법**
1. 링크 열기 (로그인 불필요)
2. **지점 / 이름** 선택 — 다음부터는 자동으로 기억됩니다
3. **제출 항목** 선택 (복수 선택 가능)
   - 신제품 연출
   - 진열 완료
   - 클린샵 체크
   - 현장 전파 확인
   - 기타 이슈
4. **사진 첨부** (최대 10장) — 원본 그대로 선택하시면 자동으로 용량이 줄어듭니다
5. 특이사항 입력 후 **제출하기**

**▶ 제출 주기**
매주 **금요일 17시까지** 주 1회

**▶ 촬영 팁**
- 매대 **전체 컷 1장 + 디테일 2~3장** 이 가장 활용도가 높습니다
- 가로 촬영, 조명 켜진 상태
- **고객 얼굴이 나오지 않도록** 주의해주세요
- POP·가격표는 글자가 읽히게 가까이 한 장

**▶ 자주 묻는 질문**
- *로그인해야 하나요?* → 아니요. 링크만 열면 됩니다.
- *잘못 냈어요* → 다시 제출하시면 됩니다. 둘 다 기록에 남습니다.
- *사진이 안 올라가요* → 와이파이/신호 확인 후 10장 이하로 나눠 제출해주세요.
- *매번 지점을 골라야 하나요?* → 처음 한 번만요. 다음부터 자동 선택됩니다.

**▶ 홈 화면에 추가하면 편합니다**
링크 열기 → 브라우저 하단 **공유** → **홈 화면에 추가**
→ 앱 아이콘처럼 바로 실행됩니다.
