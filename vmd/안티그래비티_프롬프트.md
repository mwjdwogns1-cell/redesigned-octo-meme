> **사용법**
> 1. 안티그래비티에서 **새 빈 폴더**를 워크스페이스로 연다 (예: `vmd-system`)
> 2. 아래 회색 박스를 **전부 복사** → 에이전트 입력창에 붙여넣고 실행

> ⚠️ 안티그래비티는 구글 계정에 **배포까지 해주지는 못합니다.** 파일 생성까지가 범위이고,
> 스프레드시트 연결·배포는 사람이 브라우저에서 합니다. (자동화하려면 아래 *선택: clasp* 참고)

핵심 흐름:
1) 지점 담당자가 폰에서 링크를 연다 (구글 로그인 불필요)
2) 지점·이름 선택 → 점검항목 체크 → 사진 첨부 → 제출 (30초 이내)
3) 사진은 브라우저에서 자동 압축 후 업로드
4) 서버가 파일명 규칙화 + 드라이브 폴더 자동 분류 + 시트 기록
5) VMD 담당자는 현황판에서 주차별 제출 현황과 사진을 본다
6) 매주 금요일 17시에 미제출 지점을 메일로 자동 알림

[4] 절대 바꾸지 말 것 (확정된 설계 결정)
════════════════════════════════════════
① Google Forms(구글 설문지)를 쓰지 마.
   이유: 설문지의 파일 업로드는 응답자가 반드시 구글 로그인을 해야 하고,
   폰 원본(장당 3~5MB)이 그대로 올라가 저장용량이 연 17GB에 달함.
   → 반드시 HtmlService 웹앱 + 클라이언트 사이드 압축 방식으로 구현할 것.

② 사진 압축은 서버가 아니라 브라우저(canvas)에서 한다.
   긴 변 기준 최대 1600px(설정값), JPEG 품질 0.82.
   → 장당 약 300KB, 연 2GB 미만이 되어 구글 무료 15GB로 5년 이상 감당.

③ 파일명 규칙과 폴더 구조는 이 시스템의 핵심이다. 변경 금지.
   파일명 : YYMMDD_지점_항목_NN.jpg      예) 260727_동대구_신제품연출_01.jpg
   폴더   : VMD_대구경북/YYYY/MM월/지점명/YYMMDD_항목_HHmm/
   (맨 마지막은 제출 1건당 폴더. 같은 지점이 같은 주에 여러 번 내도 안 섞이게)

④ 주 시작일은 월요일 기준. 제출 마감은 금요일 17시.

⑤ 구글 계정은 VMD 담당자 1개만 필요. 지점은 계정이 없어도 제출할 수 있어야 함.
   → 웹앱 배포 설정은 "실행: 나(소유자) / 액세스: 모든 사용자" 를 전제로 작성.

   컬럼: 제출일시 | 주시작일 | 주차 | 지점 | 지역 | 제출자 | 점검항목 |

3) 주간현황  ← 이번 주 22점 × 5항목 매트릭스, 스크립트가 값으로 갱신

[6] 서버 함수 (Code.gs)
════════════════════════════════════════
- onOpen()              커스텀 메뉴 '📋 VMD 관리' 생성
                        (최초 설정 / 제출 링크 보기 / 지점별 전용 링크 만들기 /
                         이번 주 현황 새로고침 / 미제출 알림 지금 보내기)
- setup()               시트 4개 + 지점마스터 22행 + 드라이브 루트 폴더 +
                        주간 트리거(금 17시) 생성. 여러 번 실행해도 안전(멱등)해야 함.
- doGet(e)              e.parameter.page==='admin' 이면 현황판(PIN 검증), 아니면 제출 화면.
                        e.parameter.s 가 있으면 해당 지점을 미리 선택.
- createSubmission(meta)  제출 행 추가 + 사진 폴더 생성.
                          반환 {row, folderId, prefix}. LockService 로 동시 제출 보호.
- addPhoto(folderId, prefix, index, file)  사진 1장 저장 (base64 → Blob). 반환 파일ID.
- finalizeSubmission(row, count)          사진 수 기록 + 주간현황 갱신
- refreshWeekSheet()    주간현황 시트 재계산
- weeklyReminder()      미제출 지점 집계 → 관리자 메일 발송.
                        지점마스터에 알림이메일이 있으면 해당 지점에도 개별 발송.
- listWeeks()           최근 16개 주차 목록 (현황판 드롭다운용)
- getBoard(weekKey)     해당 주차의 22점 제출 현황 반환
- getPhotos(folderId)   폴더 내 사진 썸네일을 base64 data URL로 반환 (최대 30장)
- showLinks()           웹앱 URL과 현황판 URL을 다이얼로그로 표시
- buildStoreLinks()     지점마스터 '제출링크' 열에 지점별 전용 링크 22개 일괄 생성
                        (형식: {웹앱URL}?s={지점명 URL인코딩})

※ 사진 업로드는 반드시 1장씩 순차 호출로 구현할 것.
  한 번에 여러 장을 보내면 payload 한도에 걸리고 실패 시 전체가 날아감.
  createSubmission → addPhoto × N → finalizeSubmission 순서.

[7] 화면 요구사항

■ form.html (지점 제출)
  - 입력: 지점(select) / 제출자(text) / 점검항목(체크박스, 복수선택) /

  - 제출 중에는 버튼 비활성화 + 진행률 바 표시
  - 필수값 누락 시 화면 상단에 붉은 오류 배너
  - 완료 화면: 접수된 사진 장수 안내 + '추가로 제출하기' 버튼
  - 상단에 이번 주차(예: '7/27~8/2 주차') 자동 표시

■ admin.html (담당자 현황판)
  - 상단: 주차 선택 드롭다운 + 제출률 'N/22 NN%'
  - 필터 칩: 전체 / 미제출 / 대구 / 경북 / 백화점
  - 22점 카드 그리드. 제출 지점은 왼쪽 테두리 초록, 미제출은 빨강.
    카드에 제출된 항목 태그, 사진 수, 최종 제출 시각 표시
  - 카드를 누르면 하단 시트가 올라오며 제출 상세 + 사진 갤러리(썸네일, 클릭 시 원본 열림)

## 선택: clasp로 배포까지 자동화

파일을 손으로 복사·붙여넣기 하기 싫다면, 위 프롬프트 실행 후 이어서 요청하세요.

```
clasp(Google Apps Script CLI)로 이 프로젝트를 배포할 수 있게 설정해줘.
.clasp.json, appsscript.json 을 만들고 README에 clasp login → clasp push →
clasp deploy 절차를 정리해줘. appsscript.json 의 timeZone 은 Asia/Seoul,
webapp 실행은 USER_DEPLOYING, 액세스는 ANYONE_ANONYMOUS 로 설정해줘.
```

`clasp` 사용에는 Node.js 설치가 필요합니다. 한 번 설정해두면 이후 코드 수정이 명령 한 줄로 반영됩니다.
