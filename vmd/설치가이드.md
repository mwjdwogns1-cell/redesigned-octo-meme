# 설치 가이드 (약 15분, 개발 지식 불필요)

> 준비물: **구글 계정 1개** (담당자님 것). 지점 22곳은 계정이 필요 없습니다.

---

## 1단계 — 스프레드시트 만들기

1. 크롬에서 <https://sheets.new> 접속
2. 파일 이름을 **`VMD 취합 대구경북`** 으로 변경

## 2단계 — 스크립트 붙여넣기

1. 상단 메뉴 **확장 프로그램 ▸ Apps Script** 클릭
2. 기본으로 열린 `Code.gs` 안의 내용을 **전부 지우고**, 이 폴더의 [`Code.gs`](Code.gs) 내용을 **전부 복사해 붙여넣기**
3. 왼쪽 **파일 ➕ ▸ HTML** 클릭 → 이름을 **`form`** 으로 입력
   → 생성된 내용을 지우고 [`form.html`](form.html) 내용을 붙여넣기
4. 같은 방법으로 HTML 파일 **`admin`** 생성 → [`admin.html`](admin.html) 내용 붙여넣기
5. **저장(💾)**

> ⚠️ 파일 이름은 반드시 `form`, `admin` 입니다. (`.html` 은 붙이지 않습니다)

## 3단계 — 최초 설정 실행

1. 스프레드시트 탭으로 돌아가 **새로고침(F5)**
2. 상단에 **`📋 VMD 관리`** 메뉴가 생깁니다 → **① 최초 설정 실행**
3. 권한 요청 팝업 → `계속` → 계정 선택 → **`고급` ▸ `...(안전하지 않음)으로 이동`** ▸ `허용`
   - 본인이 만든 스크립트라 뜨는 정상 경고입니다.
4. "설정 완료" 메시지가 뜨면 시트 4개와 드라이브 폴더가 자동 생성됩니다.

| 생성물 | 내용 |
|---|---|
| `지점마스터` 시트 | 22개 지점 자동 입력됨 (담당자·이메일만 채우세요) |
| `제출대장` 시트 | 모든 제출이 쌓이는 원본 DB |
| `주간현황` 시트 | 이번 주 22점 제출 매트릭스 |
| `설정` 시트 | 관리자 이메일 · 현황판 PIN · 사진 크기 |
| 드라이브 `VMD_대구경북` | 사진이 연/월/지점별로 자동 정리되는 폴더 |

## 4단계 — 웹앱으로 배포 (⭐ 가장 중요)

Apps Script 화면 우측 상단 **배포 ▸ 새 배포**

| 항목 | 설정값 |
|---|---|
| 유형 선택 (⚙️) | **웹 앱** |
| 설명 | `v1` |
| 다음 사용자로 실행 | **나** |
| 액세스 권한이 있는 사용자 | **모든 사용자** |

**배포** 클릭 → 나오는 **웹 앱 URL을 복사**

> `모든 사용자` 로 설정해야 지점에서 **로그인 없이** 제출할 수 있습니다.
> 사진은 담당자님 드라이브에 저장되며, 링크를 아는 사람만 제출 가능합니다.

## 5단계 — 링크 배포

스프레드시트 **`📋 VMD 관리 ▸ ② 제출 링크 보기`**

- **지점용 링크** → 지점 단톡방에 공유
- **관리자 현황판 링크** → 담당자님만 사용 (PIN 포함)

두 링크 모두 **폰 브라우저에서 열고 → 공유 → 홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.

## 마무리 설정 (선택)

### 지점별 전용 링크 (권장)
**`📋 VMD 관리 ▸ ③ 지점별 전용 링크 만들기`** 를 누르면
`지점마스터` 시트 **G열**에 22개 링크가 한 번에 생성됩니다.

```
https://script.google.com/.../exec?s=동대구
```

각 지점에 자기 줄의 링크를 보내면 **지점이 미리 선택된 상태**로 열려
지점 선택 실수가 사라집니다.

### 미제출 자동 알림
- 기본값: **매주 금요일 17시** 에 관리자 이메일로 미제출 지점 발송
- `지점마스터` 시트의 `알림이메일` 칸을 채우면 **해당 지점에도 개별 발송**
- 시간을 바꾸려면 Apps Script ▸ 트리거(⏰) 에서 `weeklyReminder` 수정

### 사진 용량 조절
`설정` 시트의 `사진최대크기` 기본값 **1600**(px, 긴 변 기준).
- 1600 → 장당 약 250~350KB. 22점 × 5장 × 주1회 = **연 1.5~2GB** (무료 15GB로 5년 이상)
- 화질을 더 원하면 2000, 용량을 더 줄이려면 1200

## 문제 해결

| 증상 | 조치 |
|---|---|
| 메뉴 `📋 VMD 관리` 가 안 보임 | 시트 새로고침(F5). 그래도 없으면 Apps Script에서 `onOpen` 실행 |
| 제출 시 "스크립트를 찾을 수 없음" | 4단계 배포를 안 했거나 액세스 권한이 `모든 사용자` 가 아님 |
| 코드 수정 후 반영 안 됨 | **배포 ▸ 배포 관리 ▸ ✏️ ▸ 버전 `새 버전` ▸ 배포** (새 배포 아님 — URL 유지됨) |
| 사진 여러 장에서 멈춤 | 한 번에 10장 이하 권장. 신호가 약하면 나눠서 제출 |
| 현황판이 "접근 권한 없음" | `설정` 시트의 `현황판PIN` 값과 링크 뒤 `&k=` 값이 같은지 확인 |

매장 사진에는 미출시 제품·가격 정책·고객이 찍힐 수 있습니다.
외부 클라우드(구글) 반입이 제한되는 조직이라면 **먼저 확인**하세요.

제한될 경우 대안:
- 사내 공유드라이브 + 이 문서의 **파일명·폴더 규칙만 적용** (효과의 상당 부분 확보)
- 사진에 고객이 담기지 않도록 촬영 가이드를 지점 안내문에 명시 (아래 안내문에 이미 포함)
