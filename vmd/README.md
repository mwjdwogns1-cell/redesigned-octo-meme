# 삼성스토어 대구·경북 VMD 취합 시스템

22개 지점의 VMD 사진·점검 데이터를 **주 1회** 수집하고, 자동으로 정리·보관·조회하는 시스템입니다.
구글 스프레드시트 + 앱스스크립트만 사용하며 **추가 비용이 없습니다.**

---

## 무엇이 달라지나

| | 기존 (단톡방/메일) | 이 시스템 |
|---|---|---|
| 지점 제출 | 사진 전송 + 내용 타이핑 | 링크 열고 30초, 로그인 불필요 |
| 파일명 | `IMG_2841.jpg` | `260727_동대구_신제품연출_01.jpg` |
| 저장 위치 | 대화방에 섞임, 기간 지나면 만료 | 드라이브 `연/월/지점` 자동 분류 |
| 미제출 확인 | 눈으로 세기 | 자동 집계 + 금요일 17시 자동 알림 |
| 나중에 찾기 | 사실상 불가 | 주차·지점·항목별 필터 + 사진 갤러리 |
| 사진 용량 | 장당 3~5MB | 자동 압축 장당 ~300KB (연 2GB 미만) |

---

## 구성

```
[지점 담당자]  폰에서 링크 → 지점·항목 선택 → 사진 첨부 → 제출
      │        (구글 로그인 불필요 / 사진 자동 압축)
      ▼
[앱스스크립트]  자동 처리
      ├─ 파일명 규칙화   260727_동대구_신제품연출_01.jpg
      ├─ 폴더 자동 분류  VMD_대구경북/2026/07월/동대구/260727_신제품연출_1432/
      ├─ 제출대장 기록   주차·지점·항목·사진수·특이사항
      └─ 주간현황 갱신   22점 × 5항목 매트릭스
      ▼
[VMD 담당자]  현황판(폰) — 주차 선택 → 제출/미제출 한눈에 → 카드 눌러 사진 갤러리
              스프레드시트 — 필터·피벗으로 기간별 분석
              금요일 17시 — 미제출 지점 자동 메일
```

## 취합 항목

`신제품 연출` · `진열 완료` · `클린샵 체크` · `현장 전파 확인` · `기타 이슈`

→ 항목을 바꾸려면 `Code.gs` 상단 `CHECK_ITEMS` 배열만 수정하면 제출 화면·현황판·집계에 모두 반영됩니다.

## 대상 지점 (22점)

| 지역 | 지점 |
|---|---|
| 대구 (11) | 동대구, 서대구, 북대구, 남대구, 상인역, 성서, 더현대대구*, 신세계대구*, 대백프라자*, 롯데대구*, 롯데상인* |
| 경북 (11) | 포항, 북포항, 롯데포항*, 구미, 안동, 경주, 서경주, 김천, 영천, 영주, 상주 |

`*` = 백화점 입점 (현황판에서 별도 필터 가능)

지점 추가·제외는 `지점마스터` 시트에서 행을 추가하거나 `활성` 칸을 `N` 으로 바꾸면 됩니다.

## 도입 순서 (권장)

| 시기 | 내용 |
|---|---|
| 1주차 | 설치 → **3개 지점 파일럿** (동대구·구미·포항 등) |
| 2주차 | 피드백 반영 (항목 조정) → 지점마스터 담당자·이메일 입력 |
| 3주차 | 22점 전체 확산 + 지점안내문 배포 |
| 4주차~ | 미제출 자동 알림 가동 → 월간 리포트 활용 |

한 번에 22점 배포했다가 항목을 바꾸면 신뢰를 잃습니다. **파일럿을 꼭 거치세요.**
