# 클로드 데스크탑용 인수인계 (통째로 복사)

> **사용법**: 아래 회색 박스 안의 내용을 **전부 복사** → 클로드 데스크탑 새 대화창에 **붙여넣기**.
> 레포에 접근하지 못하는 일반 클로드 앱에서도 맥락이 그대로 이어지도록 **내용을 전부 담았습니다.**
>
> 코드를 고쳐야 할 때는 `vmd/Code.gs`, `vmd/form.html`, `vmd/admin.html` 파일을
> 대화창에 **첨부**해서 같이 올리면 됩니다.

---

```
[프로젝트 인수인계 — 삼성스토어 대구경북 VMD 취합 시스템]

■ 나에 대해
나는 삼성스토어 대구·경북 지역 VMD 담당자야.
관리 지점은 22개. 지점들로부터 매장 사진, 점검 데이터, 리스트를 주 1회 취합하고,
그걸 잘 보관했다가 필요할 때 찾아 쓰고 싶어서 시스템을 만들고 있어.

■ 지금까지 진행한 것 (이미 완료)
구글 앱스스크립트 웹앱 방식으로 전체 코드 작성을 마쳤어.
소스는 GitHub 레포 mwjdwogns1-cell/redesigned-octo-meme 의
claude/samsung-vmd-data-management-u5z1bf 브랜치, vmd/ 폴더에 있고 PR #2가 열려 있어.

만들어진 파일:
- vmd/설치가이드.md   : 구글에 올리는 15분 절차 (여기부터 시작)
- vmd/Code.gs         : 서버 로직 약 590줄
- vmd/form.html       : 지점 제출 화면 (Apps Script 파일명은 form)
- vmd/admin.html      : VMD 담당자 현황판 (Apps Script 파일명은 admin)
- vmd/지점안내문.md   : 지점 단톡방에 복사할 안내문
- vmd/README.md       : 전체 개요
- vmd/이어서하기.md   : 인수인계 메모
(레포의 나머지 파일들은 무관한 이전 프로젝트니까 건드리지 마)

■ 시스템이 어떻게 도는지
1) 지점 담당자가 폰에서 링크를 연다 (구글 로그인 필요 없음)
2) 지점·이름 선택(첫 회만, 이후 자동 기억) → 항목 체크 → 사진 첨부 → 제출. 30초.
3) 사진은 브라우저에서 자동 압축된다 (긴 변 1600px, 장당 약 300KB)
4) 서버가 자동으로 처리한다:
   - 파일명 규칙화: 260727_동대구_신제품연출_01.jpg
   - 폴더 자동 분류: VMD_대구경북/2026/07월/동대구/260727_신제품연출_1432/
   - 제출대장 시트에 기록 (주차·지점·항목·사진수·특이사항)
   - 주간현황 시트 갱신 (22점 × 5항목 매트릭스)
5) 나는 현황판(폰)에서 주차를 골라 제출/미제출을 한눈에 보고,
   지점 카드를 누르면 그 지점 사진이 갤러리로 뜬다.
6) 매주 금요일 17시에 미제출 지점이 자동으로 메일로 온다.

■ 취합 항목 (5개)
신제품 연출 / 진열 완료 / 클린샵 체크 / 현장 전파 확인 / 기타 이슈
→ 바꾸려면 Code.gs 맨 위 CHECK_ITEMS 배열만 고치면 제출화면·현황판·집계에 다 반영됨

■ 대상 22개 지점
대구 11점: 동대구, 서대구, 북대구, 남대구, 상인역, 성서,
          더현대대구*, 신세계대구*, 대백프라자*, 롯데대구*, 롯데상인*
경북 11점: 포항, 북포항, 롯데포항*, 구미, 안동, 경주, 서경주,
          김천, 영천, 영주, 상주
(* 표시 = 백화점 입점 6곳, 현황판에서 별도 필터 가능)

■ 이미 확정된 설계 결정 (다시 논의하지 말 것)
1) 구글 설문지(Google Forms)는 쓰지 않는다. 이유 두 가지:
   - 설문지의 사진 첨부는 응답자가 반드시 구글 로그인을 해야 함 → 22점 정착 실패 요인
   - 폰 원본(장당 3~5MB)이 그대로 올라가 연 17GB → 무료 15GB로 1년도 못 버팀
2) 대신 앱스스크립트 웹앱. 지점은 로그인 불필요, 사진 자동 압축으로 연 2GB 미만
   → 구글 무료 15GB로 5년 이상 감당됨
3) 구글 계정은 나(VMD 담당자) 것 하나만 필요. 사진은 내 드라이브에 저장됨
4) 주 시작일은 월요일 기준, 제출 마감은 금요일 17시
5) 파일명 규칙 YYMMDD_지점_항목_NN.jpg 와 연/월/지점 폴더 구조는
   "나중에 찾을 수 있느냐"를 결정하는 핵심이라 함부로 바꾸지 않는다

■ 현재 상태
코드 작성은 끝났고, 아직 구글에 설치·배포는 안 했다.

■ 남은 할 일
1. 회사 보안 정책 확인 (외부 클라우드=구글 사용 가능 여부)
   - 매장 사진에 미출시 제품·가격 정책·고객이 찍힐 수 있어서 사내 확인 필요
   - 제한되면 사내 공유드라이브에 파일명·폴더 규칙만 적용하는 대안이 있음
2. 구글에 설치·배포 (설치가이드.md 1~5단계)
3. 지점마스터 시트에 지점별 담당자 이름·알림 이메일 입력
4. 3개 지점 파일럿 1주 (동대구·구미·포항 권장)
5. 파일럿 피드백 반영해서 취합 항목 확정
6. 22점 전체 확산 + 지점안내문 배포
7. (선택) 여러 주차에 걸친 지점별 제출률 추이 화면 추가

■ 지금 도와줬으면 하는 것
(여기에 하고 싶은 일을 적으세요)
```

| 담당자를 미리 채우고 싶을 때 | `지점마스터에 담당자를 미리 넣어줘. 동대구 홍길동, 구미 김철수, ...` |
| 화면을 고치고 싶을 때 | `현황판에 최근 8주 제출률 추이를 넣어줘. admin.html 첨부할게.` |
| 지점 안내문이 필요할 때 | `지점 단톡방에 보낼 안내 문구를 우리 지역 말투로 다듬어줘.` |
